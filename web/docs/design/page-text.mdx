The review gate reads your app's rendered text, including seed data and database text baked into code. Strong profanity blocks the deploy.

## What happens when text is blocked

A blocked deploy never goes live. The previous version keeps serving. Fix the flagged lines and ask for another deploy.

Mild words pass the gate. When in doubt, choose plainer wording. It ships faster. See [Follow the content rules](/security/moderation) for what counts.
