## Scheduled and background work

Cron wakes a sleeping app and runs a `scheduled` handler ([Cron](/guides/cron)).
Queues fan out slow work like sending messages ([Queues](/guides/queues)).

## Realtime

Chat rooms and live updates over WebSockets ([WebSockets](/guides/websockets)),
one-way streams over SSE ([SSE](/guides/sse)). Both ride the same app —
no extra services.

## Not yet

- **Code execution sandboxes** — [not available](/guides/sandboxes).
- **AI in your app** (Workers AI, Vectorize) — not available; no binding key passes deploy validation.
- **Native email sending** — use Resend over HTTP ([Email](/guides/email)).
- Native mobile apps, branches/preview environments, git push — out of scope ([Limits](/guides/limits)).
