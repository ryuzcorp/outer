## How it works

Connect your agent, ask for an app, refine it by chatting, and share the live
link. The full loop takes about ten minutes: [Quickstart](/get-started/quickstart).

## Core concepts

Three terms, used everywhere in these docs:

- **App** — a web app or website your agent built, live at `https://<slug>.outer.now`.
  Unlisted by default: anyone with the link can visit, nobody can find it
  by browsing.
- **Agent** — your AI agent (Claude, Codex, ChatGPT, …), connected to Outer
  over MCP. The agent writes the code, ships it, and reads back the result.
- **Deploy** — one shipped change. Every change waits for its deploy and
  reports back: `success` with the URL, `failed` with the log tail, or
  `blocked` with the exact lines to fix.

## What you can build

Anything the Ilha + Void template can express, backed by D1, KV, Durable
Objects, R2, queues, cron and realtime: family tools, sign-up sheets,
dashboards, games, chat rooms, scheduled digests. Concrete starters with
copy-paste prompts: [What you can build](/get-started/what-you-can-build).

::::note
Outer is in closed beta. New accounts need an invite code (`OUTER-XXXX-XXXX`). If your email is not allowed in yet and you have no code, sign-in tells you
that you are on the waitlist. [Sign in](/get-started/sign-in) has the details.
::::

## Get help

- Ask your agent first. It reads these docs over MCP (`docs` tool) and
  relays any `user_message` from a refusal verbatim. Those messages are
  written for you; don't let it improvise around them.
- Deploy stuck? [FAQ and troubleshooting](/help/faq) covers the common failures:
  sign-in, blocked deploys, and cold starts.
- Prompting tips: how to ask so your agent gets it right the first time:
  [Prompting your agent](/get-started/prompting).
