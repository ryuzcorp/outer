Every app is installable by default. Visitors on a phone can add it to their home screen and open it like a native app.

## How it works

The install icon comes from a single source file. Ask your builder for a new icon and the build regenerates matching icons and the manifest.

Two rules keep installs working:

- Icons and the manifest stay generated. Your builder never adds icon image files or a hand-written manifest.
- Reloads always fetch fresh data. Pages never serve stale cached HTML.

To rename the app on home screens, ask your builder to update the name and the page title.

For the technical detail, your builder reads [Run inside the celld runtime](/agents/platform/celld).
