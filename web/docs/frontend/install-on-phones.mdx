Every app is installable by default. Visitors on a phone can add it to their home screen and open it like a native app.

## How it works

The install icon comes from a single source: `public/favicon.svg`. Edit the SVG and the build regenerates matching icons and the manifest.

What not to break:

- Never commit icon PNGs or a hand-written manifest.
- Reloads always fetch fresh data — pages never serve stale cached HTML.

To rename the app on home screens, ask your builder to update the manifest name and the page title.

For the technical detail, your builder reads [App runtime](/agents/platform/celld).
