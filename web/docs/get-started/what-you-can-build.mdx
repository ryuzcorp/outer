Outer's bindings. Copy a prompt, swap in your own idea, and tell your agent
which guides to read.

> Build a family chat room: one room, nicknames, message history in D1.
> Read the Outer websockets guide first. No login yet — nicknames only, and
> keep it to non-private chatter: unlisted apps open for anyone with the
> link. Add sign-in ([User sign-in](/backend/user-sign-in)) before any private messages.

## Not yet

- **Code execution sandboxes** — not available.
- **AI in your app** (Workers AI, Vectorize) — not available; no binding key passes deploy validation.
- **Native email sending** — use Resend over HTTP ([Sending email](/backend/sending-email)).
- Native mobile apps, branches, and git push — out of scope ([Limits](/deploy/limits)).
