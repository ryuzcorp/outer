Get a live app in about ten minutes. The example below builds a family
grocery list. Swap in your own idea. The steps are the same.

## Connect your agent

One line per client (full table in [Connect your agent](/get-started/connect)):

- Claude Code: `claude mcp add --transport http outer https://outer.now/mcp`, then `/mcp` → `outer` to sign in
- claude.ai, Desktop, mobile: Settings → Connectors → Add custom connector → `https://outer.now/mcp`
- Codex CLI, IDE, ChatGPT desktop app: `codex mcp add outer --url https://outer.now/mcp`, then `codex mcp login outer`
- Anything else: OAuth if supported, else the emailed-code fallback in [Sign in](/get-started/sign-in)

## Ask for the app

Paste a scoped first prompt. One screen, no login, no database yet:

> Build a grocery list app for my family on Outer. One page: an input to
> add items, a list with checkboxes, a filter for bought vs. still needed.
> No login, no sharing yet — just the list. Read the Outer quickstart and
> Ilha guides first, then create the app and show me the live link.

1. Tell your agent the slug you want to use.
2. Your agent calls `create_app` with that slug.
3. Open the live link it returns: `https://<your-slug>.outer.now`.

Taken slugs are rejected, and deleted names are free to claim again immediately.
A live Ilha + Void app serves in seconds. Unlisted by default: not indexed,
reachable by link. Building a landing page, portfolio, or blog instead? Say so
in the prompt. The agent passes `template: "website"` for the content-site
shell, then copies proven patterns with the `examples` tool. See [Templates](/get-started/templates).

## Make one change

> Add a "who bought it" label: tapping a bought item lets you type a name.

1. Send the change in one short message.
2. Your agent makes the change and deploys it.
3. Read the deploy result it reports: `success` with the URL, `failed` with the log tail, or `blocked` with the lines to fix.

Code is formatted before the change lands. If a deploy fails, your agent names the file and line from the log tail. Paste that back and ask for a fix.

## Share it

1. Ask your agent to share the app.
2. It returns the URL, share text, and a QR code for the family chat.
3. Open the [Console](/get-started/console-tour) to watch the deploy, the logs, and who visits. How sharing works: [Sharing your app](/collaboration/sharing).

## Rules that bite newcomers

- Ask for the building blocks by name. Your agent reads the Ilha and Void guides before writing code, and it reads Agents → [Quickstart](/agents/start-here/quickstart) for the full loop.
- No strong profanity in page text, seed data, or the app name. The deploy is blocked and the previous version keeps serving. See [Moderation](/security/moderation).
- After each change, ask your agent what it checked. To undo, ask for a rollback, which never counts as a change. To delete, confirm with your slug typed again. The name is free to claim again immediately.
- Free gives 2 apps and 40 code changes a day ([Limits](/deploy/limits)). When your agent reports a refusal, its message is written for you. Ask it to relay that message word for word.
