---
title: Roll back a deploy
description: Restore any earlier successful deploy from the Console in one click.
---

A rollback restores any earlier successful deploy by its SHA. It never counts as a code change, and it never goes through moderation review.

1. Open Console → Deploys.
2. Find the earlier successful deploy you want.
3. Press Roll back and confirm in the modal.

The app serves that version again. Ask your agent to make a fresh change when you are ready to move forward.

Agent reference: [Follow the deploy pipeline](/agents/deploy/pipeline).
