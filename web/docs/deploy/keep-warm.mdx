---
title: Keep your app warm
description: Skip idle sleep on Pro so your app answers instantly.
---

Keep-warm is a Pro feature. Flagged fleets skip idle sleep, so the first request never pays a cold start.

1. Open Console → Settings.
2. Turn on Keep warm.

Turn it off any time, on any plan.

A deploy to a warm app also wakes it and runs one request through it, so the new version is serving before the next visitor arrives. Without keep-warm (or past the cap) the app adopts the deploy whenever it next wakes, which may be a visitor.

The host holds a cap on warm fleets: past the cap, the longest-idle warm fleet sleeps. An app whose deploy is newer than its last activity is woken first, so a deploy is never starved by busier apps. Build detail lives in [Follow the deploy pipeline](/agents/deploy/pipeline).
